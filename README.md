# KeyLaunch

KeyLaunch turns keyboard keys into shortcuts that open or switch to your apps. Download the signed app from the [notarized release](https://github.com/alfonsokkim/keylaunch/releases/tag/v1.0.0-notarized).

## Install

Requires an Apple Silicon Mac running macOS 13 or later.

1. Download `KeyLaunch.zip` and unzip it.
2. Move `KeyLaunch.app` into Applications and open it.
3. Confirm **Open** if macOS asks whether you want to open the downloaded app.
4. Enable KeyLaunch in System Settings → Privacy & Security → Accessibility so its global keyboard controls can work.

This release is a Developer ID signed, Apple-notarized copy of the existing app. It includes a stapled notarization ticket. Earlier releases and locally built copies are not covered by this notarization.
